# Session Prompt

When starting work on this project, use this order:

1. Read `PROJECT_STATUS.md`
2. Read the latest section of `MOBILE_LOG.md`
3. Inspect only the files relevant to the current task
4. After finishing, update `PROJECT_STATUS.md` if priorities changed
5. Append a short summary to `MOBILE_LOG.md`

## Suggested prompt

`Read PROJECT_STATUS.md and MOBILE_LOG.md, summarize the current context, then continue the project from there.`
